## Quy tắc cập nhật file này

Cuối phiên, nếu trạng thái dự án thay đổi, cập nhật tối thiểu các mục sau:

- ngày và commit nền;
- giai đoạn hoặc việc vừa hoàn thành;
- kết quả kiểm thử/thí nghiệm thực sự đã chạy;
- blocker hoặc quyết định mới;
- danh sách việc ưu tiên tiếp theo.

Không biến file này thành nhật ký theo ngày. Nội dung cũ cần lưu lâu dài phải chuyển sang báo cáo, kế hoạch hoặc `docs/decisions.md`; checkpoint chỉ giữ trạng thái cần thiết để phiên tiếp theo tiếp tục công việc.
